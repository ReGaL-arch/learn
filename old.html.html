Хроника веба: как родились HTML, CSS и JavaScript

Три языка, на которых построен почти каждый сайт. Узнайте, когда они появились, кто их придумал и зачем, прежде чем писать свой первый код.

HTML

Выход: 1991. HTML5: 2014.

Придумал Тим Бернерс-Ли в ЦЕРН. Это язык разметки: он сообщает браузеру, где заголовок, где абзац, а где ссылка.

CSS

Выход: 1996. Идея: 1994.

Предложил Хокон Виум Ли. Первая спецификация CSS1 вышла в декабре 1996 года. Отвечает за цвета, шрифты и раскладку.

JavaScript

Выход: 1995. Стандарт: 1997.

Брендан Эйх написал первую версию в Netscape примерно за десять дней, в мае 1995 года. Оживляет страницу: кнопки, игры, анимации.

  1. 1989Тим Бернерс-Ли предлагает идею Всемирной паутины.
  2. 1991В августе первый сайт становится доступен всем.
  3. 1993Браузер Mosaic делает интернет популярным: на страницах появляются картинки.
  4. 1994Хокон Виум Ли предлагает каскадные таблицы стилей (CSS).
  5. 1995Рождается JavaScript, а в декабре он выходит в Netscape Navigator 2.0. Выходит HTML 2.0.
  6. 1996Опубликована первая спецификация CSS (CSS1).
  7. 1997JavaScript становится стандартом ECMAScript.
  8. 1999Выходит HTML 4.01: на нём строили сайты много лет.
  9. 2014HTML5 становится официальной рекомендацией W3C.
  10. 2015Стандарт ES2015: let, const, стрелочные функции и классы.

Знаете ли вы? JavaScript не имеет отношения к языку Java: название выбрали из маркетинговых соображений. А копию самого первого сайта можно открыть по адресу info.cern.ch.
